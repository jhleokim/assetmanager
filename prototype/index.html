시세 연결 설정

브라우저는 보안정책(CORS)상 외부 금융 사이트를 직접 호출하지 못하는 경우가 있습니다. 아래 중계 서버를 순서대로 시도해 성공한 경로를 기억합니다. 중계 서버를 쓰고 싶지 않으면 모두 지우고 시세를 직접 입력해도 모든 분석 기능이 동작합니다.

공공데이터포털 인증키 (부동산 실거래가)

data.go.kr → "아파트 매매 실거래가 자료" 활용신청(즉시 승인) → 일반 인증키(Decoding) 입력

중계 서버를 경유하면 인증키가 해당 서버를 지나갑니다. 민감하다면 직접 호출이 되는 환경에서만 사용하거나, 시세를 수동 입력하세요.
